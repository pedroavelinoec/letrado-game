# \# Letrado Game

# 

# Letrado Game é um jogo em Java inspirado no Termo. O objetivo é adivinhar uma palavra de cinco letras em até seis tentativas.

# 

# \## Como jogar

# 

# Digite uma palavra de cinco letras e clique em \*\*Enviar\*\*. Use as cores para orientar o próximo palpite:

# 

# \- \*\*Verde\*\* — a letra está na posição certa.

# \- \*\*Amarelo\*\* — a letra está na palavra, mas em outra posição.

# \- \*\*Cinza\*\* — a letra não está na palavra ou já apareceu no palpite mais vezes do que ocorre na palavra secreta.

# 

# \## Como executar

# 

# 1\. No NetBeans, abra a pasta `LetradoGame` como projeto.

# 2\. Com o projeto aberto, clique em \*\*Executar\*\*.
